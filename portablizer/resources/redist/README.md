# Встроенный D3DCompiler 47

`x86/d3dcompiler_47.dll` и `x64/d3dcompiler_47.dll` — официальные компоненты
Microsoft версии `6.3.9600.18611`, извлечённые без изменений из KB4019990.
Они используются только как application-local файлы рядом с exe готового
портатива. Установка обновления Windows, WUSA и изменение системного реестра
для этого не выполняются.

Это бинарные компоненты Microsoft, а не исходный код Portablizer; к ним
применяются условия Microsoft. Сторонние зеркала DLL не использовались.

Официальные исходные пакеты и их SHA-256 записаны в `provenance.json`.
Payload Windows Update подписывается каталогом пакета; у отдельных DLL нет
встроенной Authenticode-подписи, поэтому подлинность фиксируется источником
Microsoft, версией и перечисленными хешами, а не утверждением о подписи файла.
