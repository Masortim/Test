# Встроенный D3DCompiler 47

`x86/d3dcompiler_47.dll` и `x64/d3dcompiler_47.dll` — официальные компоненты
Microsoft версии `6.3.9600.18611`, извлечённые без изменений из KB4019990.
`arm64/d3dcompiler_47.dll` — официальный компонент версии `10.0.26100.9457`
из `Windows Kits\10\Redist\D3D\arm64`. Они используются только как
application-local файлы рядом с exe готового портатива. Установка обновления
Windows, WUSA и изменение системного реестра для этого не выполняются.

Это бинарные компоненты Microsoft, а не исходный код Portablizer; к ним
применяются условия Microsoft. Сторонние зеркала DLL не использовались.

проверена действительная подпись `Microsoft Windows Kits Publisher`. Payload
KB4019990 подписывается каталогом пакета, поэтому у x86/x64 DLL нет встроенной
Authenticode-подписи: их происхождение фиксируется URL Microsoft, версией и
хешами, без ложного утверждения о подписи отдельного файла.
